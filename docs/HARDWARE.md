# Аппаратная часть: принтер T7-US и ESP32

Справочник по подключению. Все распиновки сняты с шелкографии платы и
фотографий; **перед подачей питания проверь мультиметром**.

## 1. Принтер

| Параметр | Значение |
|---|---|
| Модель / плата | GZQIANJI T7-US, плата V2.0 (20230221), совместим с APS ELM203-CH |
| Тип | Встраиваемый прямой термопринтер (direct thermal) |
| Ширина бумаги | 58 мм (57,5 ± 0,5 мм), рулон до 40 мм |
| Ширина печати | 48 мм, **384 точки** (8 точек/мм) |
| Разрешение | 203 dpi |
| Скорость | до 60–90 мм/с (зависит от данных и питания) |
| Интерфейсы | TTL UART (J2), USB (J3, не используется), RS232-вариант |
| Питание | DC 5–9 В, пиковый ток ~2 А |
| Команды | ESC/POS |
| Буфер | входной буфер; объём неизвестен, поэтому нужен DTR |

Данные с тестовой страницы принтера:

| Параметр | Значение |
|---|---|
| Baudrate | **9600** (по умолчанию) |
| Напряжение при тесте | **7,4 В** |
| Heat Density | Normal, `HEAT DOT=80`, `ON=850`, `OFF=150` |
| Версия | `S1.06 2022-05-25HcDL` |
| Auto status report | включён (`Include Auto status report!`) |

> 9600 бод — это ~960 байт/с. Картинка 384×800 (48 байт на строку, ~38 КБ)
> передаётся около 40 секунд. Для текста и QR это не критично; для фото —
> главный ограничитель скорости.

## 2. Разъёмы

```
      J1 POWER        J5 DAWER          J2 TTL&RS232        J3 USB
      ┌───────┐       ┌───────┐         ┌────────────┐      ┌──────────────────┐
      │ GND VIN│      │ 2 конт.│         │DTR TX RX GND│     │D- D+ GND VBUS GND│
      └───────┘       └───────┘         └────────────┘      └──────────────────┘
      питание        drawer kick        UART к ESP32        не используется
```

### J1 POWER — питание

| Контакт | Сигнал | Куда |
|---|---|---|
| 1 | GND | минус БП, общий GND |
| 2 | VIN | +5…9 В (рекомендуется 7,4 В) |

Питание головки и логики принтера — только сюда. **Не подавать питание на
J1 через USB и не соединять VBUS с VIN.**

### J2 TTL&RS232 — UART

Порядок по шелкографии: `DTR TX RX GND`.

| Контакт | Сигнал | Направление | Куда на ESP32 |
|---|---|---|---|
| 1 | DTR | выход принтера | GPIO4, через делитель |
| 2 | TX | выход принтера | GPIO16 (RX2), через делитель |
| 3 | RX | вход принтера | GPIO17 (TX2), напрямую |
| 4 | GND | — | GND |

- TTL-уровни принтера — **5 В**, ESP32 — **3,3 В**. Надёжнее всего
  поставить **TXS0108E** на все три линии (TX, RX, DTR); как минимум
  согласовать линии TX и DTR от принтера делителем 1 кОм / 2 кОм.
- Линия ESP32 TX → принтер RX: 3,3 В может не дотягивать до порога 5-В
  TTL/CMOS. Если печать идёт с искажениями — поставь TXS0108E и на эту
  линию.
- **DTR активен низким уровнем:** LOW = принтер готов, HIGH = занят.
  В прошивке используется `INPUT_PULLUP` и ожидание LOW — так же, как в
  библиотеке Adafruit_Thermal.
- Если DTR не подключён, прошивка определяет это при старте и печатает
  с паузами. Если подключён — ждёт готовности (до 30 с, затем ошибка).
- На плате есть RS232-вариант; для ESP32 используется TTL. Если принтер
  не отвечает — проверь, не перепутаны ли TX/RX.

### J3 USB — не используется

Порядок по шелкографии: `D- D+ GND VBUS GND`. Оставлен для справки:
USB-переходник в текущей архитектуре не нужен. Если когда-нибудь
понадобится сервисная утилита принтера, USB можно использовать отдельно,
не подключая VBUS к VIN.

### J5 DAWER — drawer kick

Два контакта для денежного ящика. Не используется.

## 3. Питание

| Вариант | Годится? | Комментарий |
|---|---|---|
| 5 В / 700 мА | Нет | Не хватит по току: пропуски, бледная печать |
| 5 В / 2,5–3 А (зарядка) | Да | Просто, но плотность/скорость ниже, чем на 7,4 В |
| 12 В 2 А + MP1584EN на 7,4 В | **Да, рекомендуется** | Совпадает с тестовой страницей; MP1584EN держит 3 А |
| 9 В напрямую | На пределе | 9 В — верхняя граница, лучше 7,4 В |

Мероприятия:

- Электролит **470–1000 мкФ** + керамика **100 нФ** как можно ближе к J1.
- Общий GND принтера, ESP32 и БП обязателен.
- ESP32 питать отдельно: от USB при отладке или от второго buck-преобразователя
  на 5 В. Не питать ESP32 от 7,4 В напрямую.
- Провода к J1 — сечением не меньше 0,5–0,75 мм², короткие.
- Принтер и ESP32 включать вместе; не оставлять линии UART подключёнными
  к выключенному ESP32 при работающем принтере.

## 4. Подключение ESP32

```
                        ┌──────────────────────┐
  12 В 2 А ── MP1584 ───┤ J1: VIN (7,4 В)      │
  (или 5 В 3 А)         │     GND              │
                        │                      │
  ESP32 GPIO17 (TX2) ───┤ J2: RX               │
  ESP32 GPIO16 (RX2) ←──┤ J2: TX   (делитель)  │
  ESP32 GPIO4        ←──┤ J2: DTR  (делитель)  │
  ESP32 GND ────────────┤ J2: GND              │
                        └──────────────────────┘
```

| ESP32 | J2 | Примечание |
|---|---|---|
| GPIO17 (TX2) | RX | через TXS0108E (или напрямую, если работает стабильно) |
| GPIO16 (RX2) | TX | через TXS0108E или делитель 1 кОм / 2 кОм |
| GPIO4 | DTR | через TXS0108E или делитель 1 кОм / 2 кОм |
| GND | GND | общий |

Делитель: R1 = 1 кОм последовательно, R2 = 2 кОм на GND, средняя точка →
GPIO. 5 В × 2/3 = 3,33 В.

Вариант на TXS0108E (предпочтительно):

| TXS0108E | Куда |
|---|---|
| VCCA | 3,3 В ESP32 |
| VCCB | 5 В принтера (или 5 В от USB) |
| GND | общий |
| OE | 3,3 В (или через 10 кОм на VCCA) |
| A1 ↔ B1 | GPIO17 ↔ J2 RX |
| A2 ↔ B2 | GPIO16 ↔ J2 TX |
| A3 ↔ B3 | GPIO4 ↔ J2 DTR |

TXS0108E auto-direction: направление определяется само, отдельный
`DIR` не нужен.

ESP32-WROOM-32 подходит. ESP32-C3/S3 тоже могут работать по Wi-Fi
(Classic BT не нужен), но у них другие пины UART/LED/DTR — их нужно
поменять в `config.h`.

## 5. SD-карта

SD-карта подключается по SPI (VSPI) и работает независимо от принтера.
Без карты принтер продолжает работать, в интерфейсе будет «нет карты».

| ESP32 | SD-модуль | Примечание |
|---|---|---|
| GPIO18 | SCK | VSPI |
| GPIO19 | MISO | вход ESP32 |
| GPIO23 | MOSI | выход ESP32 |
| GPIO21 | CS | выбран, чтобы не использовать strapping-пин GPIO5 |
| 3,3 В | VCC | если модуль 3,3-вольтовый |
| 5 В | VCC | если модуль с AMS1117/level shifter |
| GND | GND | общий |

Питание модуля:

- **3,3-вольтовый модуль** (без LDO или с обходом) — питать от 3,3 В
  ESP32, линии подключать напрямую.
- **5-вольтовый модуль** (обычный Micro SD Card Adapter с AMS1117 и
  level shifter) — питать от 5 В. Линии SPI при этом лучше прогнать через
  TXS0108E, иначе MISO может выдать 5 В на ESP32.
- Карта: **FAT32**, рекомендуется 4–32 ГБ. exFAT/карты >32 ГБ могут не
  смонтироваться.
- Провода SPI — короткие, общий GND, желательно 100 мкФ near модуль.
- Если карта не монтируется через TXS0108E, снизить частоту SPI:
  `SD_SPI_HZ` в `config.h` с 4 000 000 до 1 000 000.

### Один TXS0108E на принтер и SD

Если используется 5-вольтовый SD-модуль, один TXS0108E закрывает и
принтер, и SD (7 каналов из 8):

| TXS0108E | Сторона A (3,3 В) | Сторона B (5 В) |
|---|---|---|
| A1 ↔ B1 | GPIO17 (TX2) | J2 RX принтера |
| A2 ↔ B2 | GPIO16 (RX2) | J2 TX принтера |
| A3 ↔ B3 | GPIO4 | J2 DTR принтера |
| A4 ↔ B4 | GPIO18 | SD SCK |
| A5 ↔ B5 | GPIO23 | SD MOSI |
| A6 ↔ B6 | GPIO19 | SD MISO |
| A7 ↔ B7 | GPIO21 | SD CS |
| VCCA | 3,3 В | — |
| VCCB | — | 5 В |
| OE | 3,3 В (или 10 кОм на VCCA) | — |
| GND | общий | общий |

Если SD-модуль 3,3-вольтовый, каналы A4–B7 не нужны: подключить
напрямую.

### Формат файлов на карте

- `.bin` / `.raw` — 1-битное изображение:
  `uint16 width LE`, `uint16 height LE`, далее строки, упакованные
  MSB-first, по `(width + 7) / 8` байт. Ширина 1–384, высота 1–2000.
  Старый `image.raw` 363×800 подходит.
- `.prn` — сырой ESC/POS, отправляется на принтер как есть.
- `.txt` — текст UTF-8 с тегами форматирования; печатается потоково,
  лимит 64 КБ.
- `.md` / `.markdown` / `.csv` / `.log` — обычный текст UTF-8 без разбора
  тегов; `.md` можно заранее конвертировать в `.txt` во вкладке
  «Markdown».
- JPEG/PNG ESP32 не декодирует: изображение сначала конвертируется в
  браузере (вкладка «Фото» → «Сохранить на SD», «Markdown» или
  `convert.py`).
- Имена — ASCII, до 48 символов, расширения `.bin`, `.raw`, `.prn`,
  `.txt`, `.md`, `.csv`, `.log`.
- Лимит загрузки — 512 КБ на файл (текст — 64 КБ).

## 6. Чек-лист первого включения

- [ ] Проверена распиновка J2 мультиметром (DTR, TX, RX, GND).
- [ ] Линии TX и DTR принтера согласованы до 3,3 В.
- [ ] Общий GND у принтера, ESP32 и БП.
- [ ] На J1 подано 7,4 В (или 5 В ≥ 2,5 А), стоит конденсатор.
- [ ] ESP32 питается от USB/5 В, не от 7,4 В.
- [ ] При подаче питания принтер печатает тестовую страницу кнопкой.
- [ ] ESP32 загружается, в Serial (115200) виден IP.
- [ ] SD-карта смонтирована (в Serial `[sd] mounted` или в интерфейсе «OK»).
- [ ] Настройки → Проверить принтер отвечает.
- [ ] Тестовая страница печатается из веб-интерфейса.
- [ ] Файл `.bin` загружается на SD, открывается предпросмотр и печатается с карты.
- [ ] Текстовый `.txt` с тегами загружается на SD и печатается с карты.
- [ ] `.md` конвертируется в браузере, сохраняется как `.txt` с картинками и печатается.
- [ ] Русский текст печатается в CP1251 (кодовая страница ESC/POS 46).
- [ ] Фото 384 точки печатается без потерь строк.
