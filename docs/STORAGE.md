# Где что хранится

Карта хранилищ проекта: Wi-Fi, настройки принтера, шаблоны текста и
файлы на SD.

## Сводная таблица

| Что | Где | Переживает перезагрузку | Переживает OTA/прошивку | Сбрасывается |
|---|---|---|---|---|
| Wi-Fi SSID + пароль | NVS ESP32, Wi-Fi-стек (через WiFiManager) | Да | Да | `POST /api/wifi/reset`, полное стирание flash |
| Плотность принтера `heat` | NVS ESP32, namespace `printer`, ключ `heat` | Да | Да | полное стирание flash/NVS; вручную — `POST /api/config` |
| Шаблоны текста | SD-карта, `/templates.json` | Да | Да | удаление шаблонов, форматирование карты |
| Файлы `.bin/.raw/.prn` | SD-карта, корень | Да | Да | удаление через UI/API или форматирование карты |
| IP, SSID, RSSI, heap | оперативная память, вычисляется | — | — | перезагрузка |
| Пины, baud, лимиты | прошивка, `config.h` | — | — | пересборка/прошивка |

`localStorage` браузера **не используется**.

## 1. Wi-Fi: где лежит доступ

Пароль от домашней Wi-Fi-сети хранится **в NVS ESP32**, а не в коде и
не на SD.

Как это происходит:

1. При первом запуске WiFiManager поднимает AP `Thermal58-setup`
   (пароль `thermal58`).
2. Пользователь выбирает сеть и вводит пароль в captive portal.
3. WiFiManager вызывает `WiFi.persistent(true)` и `WiFi.begin(ssid, pass)`.
4. Wi-Fi-стек ESP32 сохраняет SSID/пароль в NVS — namespace
   `nvs.net80211` (внутренний раздел Wi-Fi-стека ESP-IDF).
5. После этого WiFiManager отключает `persistent`, чтобы служебные
   переключения режимов не затирали сохранённые данные.

Что важно:

- В коде **нет** домашнего SSID/пароля. В `config.h` только имя и пароль
  временной точки настройки: `Thermal58-setup` / `thermal58`.
- `POST /api/wifi/reset` вызывает `wm.resetSettings()` →
  `WiFi.disconnect(true, true)` и перезагружает ESP32. Wi-Fi-доступ
  стирается, поднимается `Thermal58-setup`. `heat`, шаблоны и файлы на
  SD остаются.
- `GET /api/status` показывает SSID, RSSI и IP, но **не** пароль.
- NVS не зашифрован (flash encryption/NVS encryption не включены).
  При физическом доступе к плате содержимое можно прочитать
  esptool/дампом. Для домашнего устройства это обычный компромисс;
  для улицы/офиса стоит включить flash encryption.

## 2. NVS контроллера: что хранит прошивка

Наша прошивка использует `Preferences` (обёртка над NVS) только для
плотности печати:

```text
namespace: "printer"
key:       "heat"
type:      uint8 (1..255)
default:   120
```

- Читается при старте в `printerLoadSettings()`.
- Пишется в `printerSetHeat()` при `POST /api/config`.
- Отдаётся в `GET /api/config` и `GET /api/status`.
- `POST /api/wifi/reset` его **не** трогает.
- Полное стирание flash (`pio run -t erase`, `esptool erase_flash`)
  удаляет NVS вместе с Wi-Fi; после этого `heat` снова 120.

Остальные настройки — **compile-time** в `config.h` и меняются только
пересборкой:

- `PRINTER_BAUD` (9600), пины UART/DTR/SD, `SD_SPI_HZ`;
- `HOSTNAME` (`thermal`), `WIFI_AP_NAME`, `WIFI_AP_PASS`;
- таймауты Wi-Fi, лимиты текста/QR/файлов/шаблонов, `DEFAULT_HEAT`.

## 3. Шаблоны текста на SD

Шаблоны из вкладки «Текст» хранятся на SD-карте в файле:

```text
/templates.json
{"Имя шаблона": "текст...", ...}
```

- Доступны **всем устройствам** в сети, а не только тому браузеру, где
  созданы.
- В шаблоне хранится текст с тегами форматирования как есть; при загрузке
  теги снова выполняются при печати.
- API:
  - `GET /api/templates` — все шаблоны;
  - `POST /api/templates` — `{"name":"...","text":"..."}`;
  - `POST /api/templates/delete` — `{"name":"..."}`.
- Лимиты: до 50 шаблонов, имя до 48 байт, текст до 4096 байт, файл до
  48 КБ.
- Запись атомарная: сначала `/templates.tmp`, затем переименование в
  `/templates.json`.
- Если SD-карты нет, шаблоны недоступны, кнопки сохранения/загрузки
  отключены.
- `templates.json` — служебный файл, в списке SD-файлов он не
  показывается и через `/api/sd/delete` не удаляется.
- Если `templates.json` повреждён, `GET /api/templates` вернёт 500.
  Файл можно удалить с карты (с ПК) — шаблоны начнутся с пустого списка.

## 4. localStorage браузера

Не используется. Ни шаблоны, ни настройки принтера там не хранятся.

- Шаблоны — на SD.
- `heat` — в NVS.
- Wi-Fi — в NVS.
- Состояние UI (размер шрифта, выравнивание, яркость и т. п.) — только
  в памяти страницы и сбрасывается при перезагрузке/закрытии.

## 5. SD-карта

На SD лежат файлы и шаблоны:

- `.bin` / `.raw` — 1-битные изображения с заголовком;
- `.prn` — сырой ESC/POS;
- `templates.json` — шаблоны текста;
- временные `*.tmp` на время записи (скрыты, при ошибке удаляются).

- Переживает перезагрузку, OTA и сброс Wi-Fi.
- Удаляется через UI/API или форматированием карты.
- Полное стирание flash ESP32 SD-карту не трогает.
- Файлы `.bin/.raw/.prn`: имена ASCII, расширения фиксированы;
  JPEG/PNG на карту не кладутся (конвертируются в браузере в `.bin`).

## 6. Матрица сбросов

| Действие | Wi-Fi в NVS | `heat` в NVS | Шаблоны на SD | Файлы на SD |
|---|---|---|---|---|
| Перезагрузка / `POST /api/restart` | сохраняется | сохраняется | сохраняются | сохраняются |
| OTA / `pio run -t upload` | сохраняется | сохраняется | сохраняются | сохраняются |
| `POST /api/wifi/reset` | **стирается** | сохраняется | сохраняются | сохраняются |
| `pio run -t erase` / `esptool erase_flash` | **стирается** | **стирается** | сохраняются | сохраняются |
| Форматирование SD | сохраняется | сохраняется | **стираются** | **стираются** |
| Удаление шаблона в UI/API | сохраняется | сохраняется | **удаляется один** | сохраняются |
| `POST /api/config` с новым `heat` | сохраняется | **меняется** | сохраняются | сохраняются |

## 7. Практические выводы

- Пароль Wi-Fi нигде в репозитории не лежит — его вводят один раз через
  `Thermal58-setup`.
- Чтобы сбросить только Wi-Fi — «Настройки → Сбросить Wi-Fi» или
  `POST /api/wifi/reset`.
- Чтобы вернуть плотность по умолчанию — `POST /api/config` с
  `{"heat":120}`.
- Шаблоны общие для всех устройств, потому что лежат на SD. Резервная
  копия — скопировать `templates.json` с карты или сохранить ответ
  `GET /api/templates`.
- Если нужен полный сброс «как из коробки» — стереть flash и залить
  прошивку заново; SD-карту при этом можно оставить.
