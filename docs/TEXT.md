# Форматирование текста тегами

Текст печатается как поток ESC/POS-команд. Теги в квадратных скобках
выполняются **последовательно**, как вызовы методов Adafruit_Thermal.
Закрывающие теги не нужны: тег действует до следующего тега.

## Синтаксис

- `[команда]` — без аргументов, например `[boldOn]`.
- `[команда,аргумент]` — например `[setSize,L]`.
- `[команда,арг1,арг2,...]` — например `[setHeatConfig,11,120,40]`.
- Регистр команд не важен: `[boldOn]` = `[boldon]`.
- Неизвестный тег печатается как обычный текст.
- Чтобы напечатать литерал `[`, используйте `[[`.

Пример:

```text
[setSize,L]ЗАГОЛОВОК
[setSize,M]Обычный текст, [boldOn]жирное слово[boldOff] и [underlineOn]подчёркнутое[underlineOff].
[justify,R]Итого: 1000 ₽
[justify,L][inverseOn]Инверсия[inverseOff]
```

В конце автоматически добавляется перевод строки, если текст не
заканчивается на `\n`; затем выполняется финальная подача (`feed` из API
или `[feed,N]`).

## Форматирование

| Тег | Действие |
|---|---|
| `[setSize,S]` | обычный размер |
| `[setSize,M]` | двойная высота |
| `[setSize,L]` | двойная ширина и высота |
| `[setFont,A]`, `[setFont,B]` | шрифт A или B |
| `[justify,L]`, `[justify,C]`, `[justify,R]` | выравнивание |
| `[boldOn]`, `[boldOff]` | жирный |
| `[underlineOn]`, `[underlineOn,2]`, `[underlineOff]` | подчёркивание 1/2 px |
| `[inverseOn]`, `[inverseOff]` | инверсия |
| `[doubleWidthOn]`, `[doubleWidthOff]` | двойная ширина отдельно |
| `[doubleHeightOn]`, `[doubleHeightOff]` | двойная высота отдельно |
| `[strikeOn]`, `[strikeOff]` | зачёркивание |
| `[upsideDownOn]`, `[upsideDownOff]` | перевёрнутый текст |
| `[setLineHeight,24..255]` | межстрочный интервал в точках (по умолчанию 30) |
| `[setCharSpacing,0..255]` | дополнительный интервал между символами |
| `[tab]` | табуляция |
| `[feed,0..255]` | подача строк |
| `[feedRows,0..255]` | подача в точках |
| `[setDefault]` | сброс форматирования (кодовую страницу не меняет) |
| `[reset]` | полный сброс задания, возврат к CP1251 |

## Кодировка

| Тег | Действие |
|---|---|
| `[setCodePage,46]` | CP1251 (по умолчанию) |
| `[setCodePage,17]` | CP866 |
| `[setCharset,0..15]` | таблица символов ESC/POS |

`[setCharset]` меняет таблицу символов принтера, но не конвертацию
текста в прошивке. Для кириллицы используйте `[setCodePage,46|17]`.

Кириллица корректно конвертируется для CP1251 и CP866. Для других
кодовых страниц прошивка передаёт только ASCII, остальное заменяет на
`?`. Символ `₽` в CP1251/CP866 отсутствует — печатается как `руб.`

`[setDefault]` не меняет кодовую страницу (как в Adafruit_Thermal).
`[reset]` возвращает CP1251.

## Дополнительно

| Тег | Действие |
|---|---|
| `[setBarcodeHeight,1..255]` | высота последующих штрихкодов |
| `[setPrintDensity,0..31,0..7]` | плотность и пауза (`DC2 #`) |
| `[setHeatConfig,dots,time,interval]` | параметры нагрева (`ESC 7`) |
| `[sleepAfter,N]` | сон через N секунд |
| `[sleep]`, `[wake]` | сон/пробуждение |
| `[online]`, `[offline]` | перевод принтера online/offline |

Эти команды меняют состояние принтера, а не только текст. `[offline]`
останавливает печать до `[online]`; `[sleep]` может усыпить принтер
посреди задания.

## Что не является тегами

Штрихкоды, изображения, тестовая страница и проверка бумаги — отдельные
вкладки и API-эндпоинты:

- `POST /api/barcode`;
- `POST /api/bitmap`;
- `POST /api/test`;
- `GET /api/printer/status`.

## API

Теги работают в `POST /api/text` (JSON и plain text),
`GET /api/print?text=...` и `POST /api/sd/print` для текстовых файлов
на SD.

Поля `size`, `align`, `bold`, `underline` в JSON остаются для
совместимости и задают **начальное** форматирование перед разбором
тегов. Если они не заданы, начало — S/слева/без жирного/без
подчёркивания.

```json
{
  "text": "[setSize,L]ЗАГОЛОВОК\n[setSize,S]Обычный текст",
  "feed": 2
}
```

## Текстовые файлы на SD

Отдельных шаблонов нет. Часто печатаемый текст можно хранить на SD как
обычный `.txt` (а также `.md`, `.csv`, `.log`) в UTF-8. При печати с
карты файл читается потоково, теги в нём выполняются как обычно, а
состояние форматирования сохраняется между строками и блоками чтения.
Лимит текстового файла — 64 КБ.

Загрузить и напечатать файл можно во вкладке «SD-карта» или через API
`POST /api/sd/upload` и `POST /api/sd/print`.

## Ограничения

- Текст в `/api/text` — до 4096 байт (включая теги).
- Текстовый файл на SD — до 64 КБ.
- JSON-тело до 16 КБ.
- Теги не вкладываются и не закрываются: важен порядок.
- Панель кнопок в веб-интерфейсе вставляет тег в позицию курсора;
  выделенный текст не оборачивается автоматически.
